## 📱 How to Install on Android Tablets & Phones

1. Open the **Download link** above in Google Chrome or your Android tablet's browser.
2. If Android displays *"File might be harmful"*, tap **Download anyway**.
3. Once downloaded, tap **Open**.
4. If prompted with *"For your security, your phone is not allowed to install unknown apps from this source"*:
   - Tap **Settings**.
   - Toggle **Allow from this source** to **On**.
   - Press the back button.
5. Tap **Install** (or **Update** if updating an existing version).
6. Launch **Crewtime** and sign in:
   - For Reception Kiosk mode: log in with the assigned receptionist/kiosk credentials.
   - For Manager/Owner mode: log in with the administrator account.
